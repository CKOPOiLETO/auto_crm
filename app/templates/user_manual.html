Руководство пользователя

Программный комплекс автоматизации рабочего места менеджера по подбору авто

1. Введение

Настоящее руководство предназначено для менеджеров и системных администраторов, работающих с веб-приложением AutoCRM. Программа предназначена для автоматизации процессов сбора данных с автомобильных аукционов (США), расчета логистических и таможенных расходов, а также ведения клиентской базы и формирования коммерческих предложений.

2. Назначение и условия применения

Приложение представляет собой веб-систему, которая не требует установки на локальный компьютер пользователя. Для корректной работы необходимо соблюдение следующих условий:

  • Устройство: Персональный компьютер или ноутбук под управлением ОС Windows, macOS или Linux.
  • Веб-браузер: Google Chrome, Mozilla Firefox или Microsoft Edge последних версий.
  • Подключение: Стабильное подключение к сети Интернет (для работы модулей парсинга и API НБРБ).

3. Подготовка к работе (Авторизация)

В целях безопасности доступ к системе имеют только зарегистрированные сотрудники. Для начала работы необходимо:

  1. Ввести адрес системы в адресную строку браузера.
  2. На странице входа ввести персональный Логин и Пароль, выданные системным администратором.
  3. Нажать кнопку «Войти». В случае успешной проверки учетных данных откроется Рабочий стол (Дашборд).

4. Описание операций

4.1 Парсер и калькулятор авто

Основной инструмент для работы с лотами. Для расчета стоимости автомобиля необходимо:

  1. Перейти в раздел «Калькулятор авто».
  2. Скопировать прямую ссылку на лот с аукциона (например, bid.cars) и вставить ее в поле ввода.
  3. Нажать кнопку «Спарсить». Процесс обхода защиты и загрузки данных занимает от 10 до 30 секунд. Запрещается обновлять или закрывать страницу во время работы парсера.
  4. Изучить полученную информацию (характеристики, фото) и итоговый финансовый расчет, который формируется автоматически с учетом актуальных курсов НБРБ и таможенных пошлин.
4.2 Ведение базы клиентов (CRM)

В разделе «Клиенты» менеджер осуществляет ведение своей личной воронки продаж:

  • Для добавления нового заказчика нажмите кнопку «Добавить клиента» и заполните ФИО и телефон.
  • Для быстрой навигации по таблице воспользуйтесь поисковой строкой (поиск доступен по имени, телефону или мессенджеру).
  • Изменение статуса работы с клиентом (Новый, В работе, Завершен, Отказ) доступно непосредственно в выпадающем списке напротив имени клиента без необходимости перехода в режим редактирования.
4.3 Коммерческие предложения

После получения расчетов в парсере, их можно привязать к конкретному клиенту:

  1. На странице результатов парсинга нажмите «Сохранить как Коммерческое предложение».
  2. В модальном окне выберите клиента из списка и определите маршрут логистики (Полный, Только море, Без доставки). Сумма пересчитается автоматически.
  3. Перейдите в раздел «Предложения».
  4. Нажмите кнопку «Скачать PDF» (иконка документа в списке предложений). Система автоматически сгенерирует готовый файл с фото и детализацией цены для отправки заказчику.
4.4 Функции администратора (Только для роли Admin)

Сотрудник с ролью «Администратор» имеет расширенные права:

  • Тарифы: Изменение базовой стоимости доставки (США, Море, Европа) и аукционного сбора. Для автоматического обновления курсов валют с Нацбанка РБ нажмите кнопку «Получить с НБРБ».
  • Сотрудники: Добавление новых менеджеров, смена паролей и управление ролями.
  • Аналитика: Просмотр графиков конверсии, статистики популярности авто и эффективности всех менеджеров.

5. Сообщения оператору

Система активно взаимодействует с пользователем через цветовые всплывающие уведомления (алерты):

Тип уведомления Значение и действия
Зеленое (Успех) Операция выполнена корректно (клиент добавлен, предложение сохранено, курсы обновлены). Дополнительных действий не требуется.
Желтое (Внимание) Предупреждающая информация. Например, «У вас нет прав для изменения этого предложения» (если менеджер пытается удалить чужое предложение).
Красное (Ошибка) Критическая ошибка, требующая вмешательства. Примеры: неверный пароль; обрыв соединения при парсинге; отсутствие интернета при попытке обратиться к НБРБ. В случае ошибки парсинга следует убедиться в правильности ссылки и повторить попытку через 1-2 минуты.
